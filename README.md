☁️ WikiCloud - Gerador de Nuvem de Palavras da Wikipedia

Uma aplicação web interativa, responsiva e 100% client-side que transforma qualquer artigo da Wikipedia em belíssimas obras de arte baseadas na frequência das palavras.

📖 Sobre o Projeto

O WikiCloud conecta-se diretamente à API oficial da Wikipedia para extrair artigos em tempo real. Através de um algoritmo de filtragem inteligente (que remove conectivos e stopwords indesejadas), a aplicação contabiliza as palavras mais relevantes e desenha uma Nuvem de Palavras (Word Cloud) dinâmica diretamente no navegador do usuário.

✨ Funcionalidades

🌐 Bilíngue: Suporte completo para buscas na Wikipedia em Português e Inglês, com filtros de stopwords otimizados para ambos os idiomas.

🎨 8 Temas Visuais: Escolha entre uma paleta de estilos criados cuidadosamente (Vibrante, Neon Dark, Elegante, Oceano, Pôr do Sol, Floresta, Cyberpunk e Vintage).

📐 Controle de Orientação: Gere imagens nos formatos Paisagem (16:9) ou Retrato (3:4) - perfeito para telas de computador, celulares ou para impressão.

💾 Exportação em PNG: Baixe a arte gerada em alta qualidade com um único clique, mantendo a cor de fundo fiel ao tema escolhido.

⚡ Sem Servidor (Serverless): Tudo roda diretamente no navegador do usuário. Sem necessidade de banco de dados ou backend.

📱 Responsivo: Interface construída com Tailwind CSS para funcionar perfeitamente em dispositivos móveis e desktops.

🛠️ Tecnologias Utilizadas

HTML5 & Vanilla JavaScript

Tailwind CSS (via CDN para estilização rápida e responsiva)

WordCloud2.js (Biblioteca base para a plotagem do canvas)

API Oficial da Wikipedia (Acesso nativo via REST)

Google Fonts (Poppins, Space Mono, Merriweather)

🚀 Como Executar o Projeto

Como o projeto é estático (apenas Frontend), a execução é extremamente simples:

Faça o clone deste repositório:

git clone [https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git](https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git)


Abra a pasta do projeto.

Dê um duplo clique no arquivo index.html para abri-lo no seu navegador favorito.

Alternativa: Você pode hospedar gratuitamente usando o GitHub Pages, Vercel ou Netlify.
